# KirpichVisuals (Fabric 1.21.4)

Клиентский визуальный мод. Геймплей не меняет, только картинка. Настройки: клавиша Right Shift.

- **HUD:** TargetHUD (здоровье цели), таймеры зелий, кулдауны, свечение выбранного слота хотбара.
  Каждый блок можно перетащить мышью или пальцем: Настройки -> HUD -> Двигать элементы.
- **Эффекты:** частицы ударов, шар частиц при ударе, круг при прыжке, аура вокруг цели
  (кольцо / спираль / орбита), частицы в воздухе. 11 стилей частиц.
- **Оптимизация:** далёкие частицы отсекаются, при низком FPS частицы прореживаются.

Сборка идёт через GitHub Actions: вкладка Actions -> последняя сборка -> Artifacts -> kirpichvisuals-jar.
Нужны Fabric Loader 0.16+ и Fabric API для 1.21.4.
