# FlyVisuals (Fabric 1.21.4)

Клиентский мод: TargetHUD, таймеры зелий, кулдауны, частицы ударов, оптимизация частиц.
Настройки: клавиша Right Shift.

Все файлы лежат в корне репозитория (без папок), сборка идёт через GitHub Actions.
Готовый JAR: вкладка Actions -> последняя сборка -> Artifacts -> flyvisuals-jar.
Нужны Fabric Loader 0.16+ и Fabric API для 1.21.4.
